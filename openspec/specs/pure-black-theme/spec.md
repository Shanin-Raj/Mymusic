## Requirements
### Requirement: Pure Black Theme
The application MUST use `#000000` as the primary background color. The previous brownish `#191414` color MUST be replaced to ensure an immersive, pitch-black experience on mobile devices.

#### Scenario: User opens the application on mobile
- **WHEN** the user is viewing the app
- **THEN** the background is pure black (`#000000`)
