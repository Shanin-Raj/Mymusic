## Requirements
### Requirement: Spotify 5-Tab Navigation
The bottom navigation SHALL contain 5 tabs matching the Spotify layout: Home (home icon), Search (search icon), Your Library (library_music icon), Premium (spotify icon or similar), and Create (add/create icon).

#### Scenario: User navigates the app
- **WHEN** the user taps on different tabs in the bottom navigation
- **THEN** the active tab icon changes to a filled state and the corresponding screen is displayed
