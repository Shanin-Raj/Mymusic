## Requirements
### Requirement: Playlist Song Removal
The application MUST allow users to remove a song from a specific playlist without deleting the song from the main library.

#### Scenario: User removes a song from a playlist
- **WHEN** the user clicks the "Remove from Playlist" icon on a track within the Playlist details screen
- **THEN** the song is removed from the current playlist but remains available in the main Library
