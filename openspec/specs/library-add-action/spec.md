## Requirements
### Requirement: Add Music from Library Header
The application SHALL NOT have a dedicated "Create" tab in the bottom navigation. Instead, it MUST provide a `+` icon in the header of the "Your Library" screen that opens the Add Music modal.

#### Scenario: User wants to add new music
- **WHEN** the user taps the `+` icon on the Library screen
- **THEN** the Add Music modal is displayed
