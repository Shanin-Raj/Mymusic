## ADDED Requirements

### Requirement: Full-Screen Player Status Bar Safe Area
The full-screen player's AppBar (back button, title) MUST be inset below the system status bar so that no content overlaps with the status bar area.

#### Scenario: Open full-screen player
- **WHEN** the user opens the full-screen player
- **THEN** the AppBar's back button and title text MUST be fully visible below the system status bar, without any overlap or clipping.
