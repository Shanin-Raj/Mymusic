## ADDED Requirements

### Requirement: Spotify Library View
The library screen SHALL include a top filter chip row (Playlists, Podcasts, Albums, Artists) and a list of playlists/albums displayed as horizontal items with square thumbnail art.

#### Scenario: User navigates to Your Library
- **WHEN** the user opens the Library tab
- **THEN** they see filter chips at the top and their playlists/songs in a list with square cover art thumbnails
