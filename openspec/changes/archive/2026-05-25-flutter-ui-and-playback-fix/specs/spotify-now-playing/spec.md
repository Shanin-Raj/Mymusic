## MODIFIED Requirements

### Requirement: Interactive Player Controls
The system SHALL provide a full-screen player window with album art, precise seek controls, and a complete suite of playback utilities.

#### Scenario: User opens player window
- **WHEN** the user taps the persistent MiniPlayer
- **THEN** the system SHALL display the full-screen player with:
    - Large album artwork
    - Progress slider with current/total time
    - Play/Pause, Next, Previous, Shuffle, and Repeat buttons
    - Functional "Like" button (Heart)
    - "Up Next" Queue viewer button
    - Sleep Timer configuration button
