## ADDED Requirements

### Requirement: Real-time Library Search
The system SHALL provide a search interface that filters the music library based on track name or artist as the user types.

#### Scenario: User searches for a track
- **WHEN** the user types "Beatles" in the search bar
- **THEN** the system SHALL immediately display all tracks where the name or artist contains "Beatles"
- **AND** allow the user to play them directly from the results
